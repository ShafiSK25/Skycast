# Skycast

React weather dashboard with live conditions, rain chance, humidity, wind and a 3-day forecast.

🔗 **Live demo:** https://skycast21.netlify.app/

## Setup
1. Clone the repo and run `npm install`
2. Create a `.env` file with `VITE_WEATHER_API_KEY=your_openweather_key`
3. Run `npm run dev`
